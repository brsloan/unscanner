      Local / OpenAI-compatible endpoint
      
      
      The API root; /chat/completions is added automatically (pasting the full endpoint is fine too).
      
      
      
         
         
         
      
      
      
        Reasoning models such as Qwen 3 otherwise spend their whole output on thinking and return nothing for a page. Leave ticked unless the endpoint rejects it.
      
      
      
        A page is rarely over 3000. "Output truncated" usually means the model got stuck repeating itself; the page is retried automatically, and a higher number here only makes a stuck page slower.
      
    
      
    
      When a model refuses a page
      
      
        A page one model refused and another transcribed is marked needs review.
      
      
      
        The title helps with headings, but a well-known title makes some providers refuse. Untick for a document that keeps getting refused.
